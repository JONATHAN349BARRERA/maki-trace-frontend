# Contrato de la API REST

Todas las rutas cuelgan de `VITE_API_URL` (por defecto `/api`), intercambian JSON
y, salvo el login, exigen `Authorization: Bearer <token>`. Errores:
`{ "message": "…" }` con 400 (validación), 401 (sesión), 403 (permiso), 404, 409 (conflicto).

| Método           | Ruta                                                                                     | Roles                                      | Descripción                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------ | --------------------------------------------------------------------------- |
| POST             | `/auth/login`                                                                            | público                                    | `{usuario, password}` → `{token, usuario}`                                  |
| GET              | `/auth/me`                                                                               | todos                                      | Usuario de la sesión                                                        |
| GET/POST         | `/usuarios`                                                                              | gerente                                    | Listar / crear usuarios                                                     |
| PUT              | `/usuarios/:id`                                                                          | gerente                                    | Editar usuario, rol o contraseña                                            |
| GET/POST         | `/clientes`                                                                              | gerente, gestor (lectura)                  | Clientes                                                                    |
| PUT              | `/clientes/:id`                                                                          | gerente                                    | Editar cliente                                                              |
| GET              | `/contratos`                                                                             | todos (cliente: solo los suyos)            | Contratos con vigencia calculada                                            |
| GET              | `/contratos/:id`                                                                         | ídem                                       | Detalle                                                                     |
| POST / PUT       | `/contratos`, `/contratos/:id`                                                           | gerente                                    | Crear / editar                                                              |
| GET              | `/equipos?contratoId=`                                                                   | todos (cliente: solo los suyos)            | Equipos                                                                     |
| GET              | `/equipos/:id`, `/equipos/serial/:serial`                                                | ídem                                       | Hoja de vida (por id o por serial del QR)                                   |
| POST / PUT       | `/equipos`, `/equipos/:id`                                                               | gerente, gestor                            | Crear / editar                                                              |
| POST             | `/equipos/:id/lecturas`                                                                  | todos                                      | `{valor}` lectura del contador                                              |
| POST             | `/equipos/:id/fotos`                                                                     | gerente, gestor, técnico                   | `multipart/form-data` campo `foto`                                          |
| DELETE           | `/equipos/:id/fotos/:archivoId`                                                          | gerente, gestor                            | Quitar foto                                                                 |
| GET              | `/archivos/:id`                                                                          | —                                          | Archivo binario                                                             |
| GET              | `/casos?estado=&equipoId=&contratoId=`                                                   | todos (cliente: suyos; técnico: asignados) | Casos                                                                       |
| GET              | `/casos/:id`                                                                             | ídem                                       | Detalle con bitácora                                                        |
| POST             | `/casos`                                                                                 | cliente, gestor, gerente                   | `{equipoId, tipo, descripcion, itemsSolicitados}`                           |
| POST             | `/casos/validar`                                                                         | todos                                      | Prevalidación de una solicitud (advertencias)                               |
| GET              | `/casos/:id/validacion`                                                                  | gerente, gestor                            | Advertencias antes de aprobar                                               |
| POST             | `/casos/:id/aprobar`                                                                     | gerente, gestor                            | `{confirmarAdvertencias?, nota?}`; 409 + `advertencias` si faltan confirmar |
| POST             | `/casos/:id/rechazar`                                                                    | gerente, gestor                            | `{nota}`                                                                    |
| POST             | `/casos/:id/asignar`                                                                     | gerente, gestor                            | `{tecnicoId, fechaProgramada?}`                                             |
| POST             | `/casos/:id/iniciar`                                                                     | técnico asignado, gestor                   | Inicia la atención                                                          |
| POST             | `/casos/:id/cerrar`                                                                      | técnico asignado, gestor                   | `{descripcion, contador?, itemsUsados}`                                     |
| GET              | `/items?modelo=`                                                                         | todos (cliente: sin costos)                | Repuestos y suministros                                                     |
| GET / POST / PUT | `/items/:id`, `/items`                                                                   | gerente, gestor                            | Ítems                                                                       |
| GET / POST       | `/movimientos?itemId=`                                                                   | gerente, gestor                            | Kárdex / `{itemId, tipo, cantidad, costoUnitario?, nota?}`                  |
| GET / POST / PUT | `/tecnicos`, `/tecnicos/:id`                                                             | gerente (escritura), gestor                | Personal técnico y labores                                                  |
| GET              | `/facturas`                                                                              | gerente                                    | Facturas con estado y mora                                                  |
| POST             | `/facturas/generar`                                                                      | gerente                                    | `{periodo: "AAAA-MM"}`                                                      |
| POST             | `/facturas/:id/pago`                                                                     | gerente                                    | `{fechaPago?}`                                                              |
| GET              | `/alertas`                                                                               | gerente, gestor                            | Alertas activas                                                             |
| GET              | `/informes/dashboard`, `/informes/casos`                                                 | gerente, gestor                            | Tablero e informe de casos                                                  |
| GET              | `/informes/personal`, `/informes/inventario`, `/informes/contratos`, `/informes/cartera` | gerente                                    | Informes                                                                    |
